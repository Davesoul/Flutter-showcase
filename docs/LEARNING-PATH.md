# Learning path

Ordered exercises. Each takes 15–45 minutes and ends with a visible change
plus a rebuild. Check off as you go.

## Level 0 — Install (true beginners start here)

- [ ] In-app Foundations → Setup: follow steps 1–4, run `flutter doctor`
      until the checks you need are green.
- [ ] `flutter create hello_first` + `flutter run -d chrome`. Change the
      counter text, save, watch hot reload update the browser.
- [ ] In-app Foundations → Dart 101: read ideas 1–7, then 8–14.

## Level 1 — Orient

- [ ] Run it (`01`), resize through all 3 breakpoints, note the badge.
- [ ] Read `catalog.dart`, then read `08` and add a 10th demo (Toast component).
- [ ] Theming studio: all 6 seeds × light/dark. Pick your favourite combo.
- [ ] Dart 101 page: read the 7 ideas, tap Open on 3 usage rows.

## Level 2 — Foundations

- [ ] `02`: build `PillTag` in core/widgets, use it in Storefront + Chat.
- [ ] `03`: 360px audit — screenshot all 8 demos, fix any overflow.
- [ ] `04`: cart quantities (`Map<String,int>`) — notifier + 2 readers only.

## Level 3 — Go deeper

- [ ] `05`: 5th motion card (tap-to-fill progress ring).
- [ ] `05-hard`: rebuild the stagger with raw `AnimationController`s.
- [ ] `06`: 4th chart (radar/scatter) on a new const series.
- [ ] `08`: full recipe — new component end-to-end in under 20 min.

## Level 4 — Ship

- [ ] `07`: local Pages simulation, zero console 404s.
- [ ] Push to GitHub, enable Pages, open the live URL on your phone.
- [ ] Break base-href on purpose (`--base-href="/wrong/"`), see the white
      screen, fix it. You now diagnose every blank Pages deploy in 1 minute.

Reading order for reference: 01 → 08 → 02 → 03 → 04 → 05 → 06 → 07.
