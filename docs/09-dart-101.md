Companion to the in-app **Foundations → Dart 101** page (the primary
text — 14 language ideas with highlighted samples, 16 everyday widgets
each with its smallest usage, a complete 30-line first app, and a
tap-to-open where-used table). Read it in the app. This file is the
cheat-sheet plus extension notes. For environment setup see 00-setup
and the in-app **Foundations → Setup** page.

## The 14 ideas (app page has samples + a first app)

1. **final vs const** — runtime-once vs compile-time. `const` widgets let
   Flutter skip rebuild work.
2. **Null safety** — non-nullable by default; `?` allows, `?.` chains,
   `??` falls back, `!` asserts (and can crash).
3. **Arrows** — one-expression callbacks: `onTap: () => select(i)`.
4. **Spread + collection-for** — `[...a, ...b]`, `[for (t in ts) Tile(t)]`.
5. **Classes** — final fields + generative (often `const`) constructor.
6. **async/await** — pauses the function, never the UI thread.
7. **Interpolation** — `'$var'` / `'${expr}'` inside strings.

## Extending the page

`learn_page.dart` is three const lists (`_ideas`, `_widgets`, `_usages`)
plus four small widgets. To add an idea: append one `_Idea(title, body,
sample)` — the `_CodeBox` highlights it automatically via
`highlightDart`. To cover a new widget: one `_WidgetEntry` line, and if
the library uses it, one `_Usage` row pointing at its section label.

## The highlighter (`core/dart_highlight.dart`)

Single-pass scanner, no packages: comments (line + block), strings
(single/double/triple with escapes), `@annotations`, numbers
(dec/hex/double), the Dart keyword set, UpperCamelCase types. Colours come
from the active `ColorScheme`, so code re-skins with the theming studio.
Adjacent same-style runs merge, keeping a 400-line file to dozens of
spans. Known limits (documented in the file header): no interpolation
spans, no error recovery.
